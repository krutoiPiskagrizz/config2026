# config2026
Практическая работа №1. Эмулятор языка оболочки ОС

Вариант №24. Консольный эмулятор оболочки UNIX-подобной ОС с виртуальной файловой системой (VFS), которая целиком хранится в памяти.

Язык: Python 3 (сторонние библиотеки не нужны).

Запуск: python3 emulator.py --vfs <путь к CSV с VFS> [--script <путь к стартовому скрипту>] Параметр Обязательный Описание --vfs да путь к физическому расположению VFS --script нет путь к стартовому скрипту

При запуске эмулятор выводит все заданные параметры (строки [debug]). Если указан --script, оманды из него выполняются по очереди, ввод и вывод отображаются на экране как в диалоге с пользователем, ошибочные строки пропускаются. После скрипта эмулятор переходит в интерактивный режим.

Приглашение к вводу: user@<имя VFS>:<текущий каталог>$

Имя VFS берётся из имени CSV-файла (vfs/several.csv → several).

Парсер

Строка разбирается на команду и аргументы с учётом кавычек: ls "my folder" передаёт один аргумент my folder. Незакрытая кавычка, неизвестная команда и неверные аргументы дают сообщение об ошибке, эмулятор при этом продолжает работать. Формат VFS (CSV)

Источник VFS: CSV-файл с заголовком path,type,content.

Столбец Значение path полный путь от корня, например /home/user/a.txt type dir (каталог) или file (файл) content содержимое файла в base64 (для каталогов пусто)

Вложенность задаётся полным путём, промежуточные каталоги создаются автоматически. Файл не распаковывается и не изменяется, все операции выполняются в памяти.

Ошибки загрузки VFS (файл не найден, неверный заголовок, невалидный base64, конфликт путей) выводятся с описанием причины.

Команды Команда Описание ls [-l] [путь...] список содержимого каталога, -l показывает тип и размер cd [путь] смена каталога, без аргумента переход в корень uptime время работы эмулятора cal [[месяц] год] календарь: текущий месяц, месяц года или весь год rm [-r] путь... удаление файлов, -r для каталогов (только в памяти) help список команд с описанием exit выход из эмулятора Структура проекта emulator.py # эмулятор vfs/ # примеры VFS: минимальный, несколько файлов, 3+ уровня вложенности scripts/ # стартовые скрипты (.emu) и скрипты тестирования (.sh) Тестирование bash bash scripts/stage2_config.sh # параметры командной строки bash scripts/stage3_vfs.sh # разные варианты VFS и ошибки загрузки python3 emulator.py --vfs vfs/several.csv --script scripts/all_commands.emu # все команды

Этапы работы

REPL: прототип с приглашением, парсером и командами-заглушками ls, cd, exit. Конфигурация: параметры командной строки, отладочный вывод, стартовый скрипт. VFS: загрузка виртуальной файловой системы из CSV. Основные команды: ls, cd, uptime, cal. Дополнительные команды: rm, help.
